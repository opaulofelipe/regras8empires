# Manual do Jogo

Arquivos:
- `index.html` — página principal
- `styles.css` — visual e responsividade
- `script.js` — ampliação das imagens e destaque da navegação
- `assets/` — imagens do manual e das cartas

## Como usar
Abra `index.html` no navegador.

## GitHub Pages
Envie todo o conteúdo desta pasta para o mesmo repositório, mantendo a pasta `assets`.
Depois, publique a branch pelo GitHub Pages.

O layout mantém:
- imagens de regras em uma coluna;
- cartas individuais em duas colunas, inclusive no celular;
- imagens sem recorte;
- clique/toque para ampliar.
