# 8 Empires — Manual de Regras

Site estático pronto para GitHub Pages.

## Arquivos
- `index.html` — estrutura e conteúdo do manual
- `styles.css` — layout responsivo e identidade visual
- `script.js` — navegação, progresso de leitura, botão de topo e ampliação das cartas
- `assets/cartas/` — cartas otimizadas em WebP
- `assets/recursos/` — ícones dos quatro recursos

## Publicação
Envie todo o conteúdo desta pasta para a raiz do repositório do GitHub Pages, mantendo a estrutura de pastas.

O botão **Sortear objetivos** aponta para:
`https://opaulofelipe.github.io/objetivos8empires/`
